## DevOps | lab1| Генератор паролей | Python

Консольное приложение для безопасного хранения и управления паролями. 

### Возможности

- **Защита мастер-паролем** - вход по хэшу SHA-256 с солью
- **Шифрование записей** - все пароли зашифрованы алгоритмом Fernet
- **Управление записями** - добавление, просмотр, удаление
- **Генератор паролей** - создание надёжных случайных паролей
- **Скрытый ввод** - мастер-пароль не отображается при вводе
- **JSON-хранилище** - данные сохраняются в файле

### Установка
1. Проверить наличие Python
```bash
   python3 --version
```
2. Установить зависимости
```bash
pip install -r requirements.txt
```
### Работа с приложением
1. Первый запуск - создание мастер-пароля
```bash
python3 -m password_manager.cli --init
```
2. Вход в менеджер паролей:
```bash
python3 -m password_manager.cli --unlock
```
После разблокировки доступны команды:

* Add entry note - добавить новую запись (сервис, логин, пароль)

* List of all entries - показать список всех сервисов (без паролей)

* Get your entry - получить логин и пароль для конкретного сервиса

* Delete your entry - удалить запись

* Generate new password - сгенерировать случайный надёжный пароль

* Exit - выйти из программы

3. Чтобы сгенерировать пароль стандартной длины (16 символов), введите
```bash
python3 -m password_manager.cli --generate
```
или же можно явно указать желаемую длину пароля:
```bash
python3 -m password_manager.cli --generate 10
```
4. Также доступна справка по командам:
```bash
python3 -m password_manager.cli --help
```
5. Автоматический запуск тестов
```bash
python3 -m pytest tests/ -v
```
